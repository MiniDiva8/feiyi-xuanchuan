# 前端参考资料与采用方式

| [Jasper](https://www.jasper.ai/knowledge-base)                                         | 官方品牌知识库说明                       | 私有品牌资料与通用模板的边界             |

最终方向：深墨绿导航、纸白工作区、克制的陶土/草木点缀。登录与概览使用原创工艺氛围图，业务页用真实档案、状态、版本与操作形成层次。没有复制第三方前端代码、品牌标识、照片或模板。

本项目是商家工作台。公共文化门户的首页层级不能直接套用到业务操作页；导航、编辑、审核和数据录入结合现有完整营销闭环重新组织。
