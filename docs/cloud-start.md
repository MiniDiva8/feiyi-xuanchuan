# Cloud Start skill 的就绪说明

这是可复制到当前 Cloud 环境 Start skill 的仓库级就绪指令，不是自动部署或环境管理 API。

- 找到 MiniDiva8/feiyi-xuanchuan 的实际仓库目录，读取根 AGENTS.md。
- 检查 Python 3.11+、Git 2.38+；报告 Git 根目录、当前分支和工作区是否有改动。
- 检查环境能通过本人连接读取目标仓库；不打印凭据、完整环境变量或 gh token。
- 本套件没有常驻服务；不要额外启动服务器。
- 环境准备阶段不认领 Issue、不创建任务分支、不提交、不推送、不创建 PR。
- 每次收到具体任务后，再核对 Issue、唯一负责人、路径和验收标准，执行 start 拉取最新 main。
- 已有任务有未提交改动时保留原状；不要自动 reset、stash 或切换分支。
- 若缺少权限或工具，给出确切未通过项。通过的检查列实际证据，未运行的检查保留未验证。
